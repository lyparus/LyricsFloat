# Текст песни (LyricsFloat)

Android-приложение: показывает текст трека, который играет в Яндекс Музыке (или любом плеере),
в плавающем окне поверх всех приложений. Тексты — из открытой базы LRCLIB, синхронизированные
строки подсвечиваются в такт.

## Установка
1. Скопируйте `LyricsFloat.apk` на телефон и откройте (разрешите установку из этого источника).
2. В приложении: «Открыть настройки доступа» → включите «Текст песни».
   Если переключатель серый — «О приложении» → ⋮ → «Разрешить ограниченные настройки», и снова.
3. «Разрешить показ поверх окон» → включить.
4. Включите «Показывать текст» и запустите трек в Яндекс Музыке.

Окно: перетаскивать за заголовок, 🔍 — поиск в Genius, ▾ — свернуть, ✕ — выключить.

## Сборка
JDK 17 и Android SDK. Из папки проекта:

    set JAVA_HOME=%USERPROFILE%\android-build-tools\jdk-17.0.20.1+1
    gradlew.bat assembleDebug

APK: `app\build\outputs\apk\debug\app-debug.apk`.

Код: `app/src/main/java/io/github/lyricsfloat/`
- `MediaListener.kt` — читает текущий трек из медиасессии
- `LyricsFetcher.kt` — поиск текста в LRCLIB, разбор LRC
- `Overlay.kt` — плавающее окно
- `MainActivity.kt` — экран настроек
